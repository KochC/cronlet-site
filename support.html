How does Cronlet run my shortcuts?

iOS doesn't let apps start shortcuts directly. Cronlet sends a notification when a job is due, and one Shortcuts automation (not a new shortcut) reacts to it and runs the shortcut that is due. You set it up once; it works for all jobs.

Setting up the automation (once)

  1. Shortcuts app → Automation tab → +.
  2. Trigger: app notifications → choose Cronlet → Run Immediately → New Blank Automation.
  3. Add Cronlet's Get Due Shortcut (leave the field empty).
  4. Add Get My Shortcuts.
  5. Add Repeat with Each over the result of Get My Shortcuts.
  6. Inside the loop: If Repeat Item → Name → is → result of Get Due Shortcut.
  7. Inside the If: Run Shortcut → Repeat Item.

Requirements

Notification automations require iOS 27 or later. Without the automation, tap a Cronlet notification to run the shortcut.

The shortcut isn't found

The job's shortcut name must match the name in the Shortcuts app exactly (spaces and capitalisation included).
